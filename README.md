## 🎯 Problem Statement

Security scanners and CTF tools return a verdict or a raw log, but not the reasoning behind it — students see "vulnerable" without ever seeing why, so the underlying skill never actually transfers, and real-world exploit-finding stays a black box even after using the tool.

## 🚀 Getting Started

### 1. Install Dependencies

```bash
npm install
```

### 2. Configure Environment

```bash
cp server/.env.example server/.env
```

### 3. Run Development Servers

- **Frontend:** `npm run dev:client`
- **Backend:** `npm run dev:server`
